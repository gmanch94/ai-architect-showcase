Anchor Doctrine

Data > Models

"Performance differences between algorithms are relatively small when compared to differences between same algorithms with more or less data."

— Halevy, Norvig, Pereira (2009), The Unreasonable Effectiveness of Data, IEEE Intelligent Systems 24(2)

Strategic implication: invest in data infrastructure, labeling, and quality before fancy algorithms. The "unreasonable effectiveness of data" is the leverage point.

NLP

Most enterprise data is text. Most enterprises ignore it.

  • Customer reviews, support tickets, emails, contracts, transcripts, documents
  • NLP turns this unstructured corpus into features → predictions
  • Sentiment, topic modeling, named entity, classification — all off-the-shelf
  • Modern path: embeddings + vector search + LLM (RAG) — no labels required

Pick one NLP use case (sentiment of churn signals, topic of support tickets, RAG over your knowledge base) and ship it end-to-end this quarter.

RAG vs Fine-tuning

Customize a foundation model: pick your lever

RAG (Retrieval-Augmented Generation)

What: Look up relevant info from your KB, paste into prompt.
Cost: Low
Freshness: Real-time
Use first when: Need to ground answers in private/factual data.

Fine-tuning

What: Train the model on your examples.
Cost: High (compute + data + labeling)
Freshness: Static — needs retraining
Use only when: Domain voice/format/style requires it.

Default: Start with prompt engineering → RAG → only then fine-tuning.

Your 90-day activation plan (2026 edition)

  • Week 1: Charter AI governance committee (Legal, Security, HR, Data, business sponsor). Single accountable owner. Inventory shadow-IT AI use.
  • Weeks 2–4: Run readiness scorecard. EU AI Act gap check (GPAI obligations live 2 Aug 2025; high-risk system rules 2 Aug 2026). Map shadow IT to stack layers.
  • Weeks 4–6: Stand up eval harness BEFORE any production rollout. Define accuracy / hallucination / bias thresholds per use case. No evals → no deploy.
  • Weeks 4–8: Ship 1–3 assistant rollouts (Copilot-class) for fast credibility — measurable on PR throughput, ticket resolution, or doc cycle time.
  • Weeks 6–10: Publish prompt cookbook, risk checklist, NIST AI RMF mapping. AI literacy program (mindmap + glossary).
  • Weeks 8–12: Pilot ONE agentic workflow (narrow scope, human checkpoint, audit log). Charter 2–3 H2 automation projects with named sponsors and kill criteria.
